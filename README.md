# Тестовое задание: Парсер погоды

Скрипт на Python для получения данных о погоде через API wttr.in.

## Как запустить:
1. Убедитесь, что файл `cities.txt` находится в одной папке со скриптом.
2. Запустите: `python weather_app.py`

## Ограничения:
Используются только стандартные библиотеки Python (json, urllib).
